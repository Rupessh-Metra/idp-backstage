# Ksquare IDP

Welcome to the docs for **Ksquare IDP**, The Ksquare Group's internal
developer portal, built on [Backstage](https://backstage.io).

This page is rendered by TechDocs directly from the `docs/` folder in this
repository — edit `docs/index.md` (or add more pages and list them in
`mkdocs.yml`'s `nav`) and the rendered content here updates the next time
TechDocs builds this site.

## What lives here

- The Backstage app itself (frontend + backend) that powers this portal.
- The software catalog, scaffolder templates, Kubernetes integration, and
  RBAC policy that make up the platform.

## Where to go next

- Browse the **Catalog** to see registered components, APIs, and systems.
- Use **Create** to run a scaffolder template (e.g. deploy to Kubernetes,
  grant repo access).
- Check the repository `README.md` for local setup instructions.
